# Entscheidungen

Entscheidungen dieses Projekts, jede mit Datum, Wortlaut, Grund und Folgen. Neue Einträge kommen ans Ende; eine überholte Entscheidung bleibt stehen und bekommt einen Verweis auf die neue.

Die Entscheidungen des Starters stehen in `docs/STARTER_DECISIONS.md`. Die Datei gehört zum Kit: `bin/starter sync` zieht sie nach, das Projekt ändert sie nicht. Eine Kennung wie E-05 in Code, Regeln und Dokumenten des Kits verweist dorthin. Eigene Einträge zählen als P-01, P-02 und so weiter, damit sie nie mit einer späteren Entscheidung des Starters zusammenfallen; weicht das Projekt von einer Entscheidung des Starters ab, nennt der Eintrag deren Kennung.

Aufbau eines Eintrags:

```md
### P-01 (Datum): Titel

- **Entscheidung:** was gilt
- **Grund:** warum
- **Folgen:** was sich dadurch ändert
```
